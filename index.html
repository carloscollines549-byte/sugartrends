☁️ Supabase Cloud Sync

⚠️ Cloud sync not configured — data only exists in this browser. Set up Supabase to sync across devices and share with KSB stakeholders.

One-time setup (5 minutes):
1. Go to supabase.com → log in with your existing account → New Project
2. Once created, go to SQL Editor and run this once:
CREATE TABLE ksb_store (
  key TEXT PRIMARY KEY,
  value TEXT NOT NULL,
  updated_at TIMESTAMPTZ DEFAULT now()
);
ALTER TABLE ksb_store ENABLE ROW LEVEL SECURITY;
CREATE POLICY "anon_all" ON ksb_store FOR ALL TO anon USING (true) WITH CHECK (true);
3. Go to Project Settings → API → copy your Project URL and anon public key
4. Open this HTML file, find the two lines at the top of the <script>:
const SUPABASE_URL = ''; and const SUPABASE_ANON = '';
5. Paste your values, save, and redeploy to Netlify — done.
The anon key is a public read key — safe to embed here (Row Level Security controls access).

🦙 Ollama Local AI Brain

Run AI entirely on-premise. Ollama hosts LLMs locally (llama3.2, mistral, gemma2, etc.) so no sugar-sector data ever leaves KSB's network. Falls back to Gemini cloud only if local AI is offline.

One-time setup (KSB IT / Intern):
1. Install Ollama: curl -fsSL https://ollama.com/install.sh | sh
2. Pull a model: ollama pull llama3.2
3. Start with CORS (so the browser can reach it):
OLLAMA_ORIGINS=* ollama serve
4. If dashboard is on Netlify and Ollama is on a LAN PC, enter that PC's IP above (e.g. http://192.168.8.101:11434)
Data never leaves your network. The dashboard sends article text to your local machine, not to Google/x.ai.

☁️ OpenRouter Cloud AI (Primary Backend)

OpenRouter provides unified access to Gemini, Claude, Llama, GPT-4o and 200+ models via one API key. This is the default cloud AI for Sugartrends when Ollama is offline. Your key is stored in browser localStorage — never transmitted to our servers.

How it works:
1. Your API key is saved in localStorage only — it never hits our Netlify functions or Supabase.
2. The dashboard calls OpenRouter directly from your browser (CORS-enabled).
3. If OpenRouter fails, it auto-falls back to Gemini (Google AI Studio key).
4. If you also run Ollama locally, local AI takes priority for complete data privacy.
Priority: Ollama (local) → OpenRouter (cloud) → Gemini (fallback). All three can coexist.

💾 Local Backup & Restore

Everything in this dashboard lives in your browser only — there is no shared server. If you clear browser data, switch devices, or the browser's storage gets reset, everything is lost unless you've backed it up. Download a full backup regularly, especially before clearing browser data.

Predicts retail sugar price from a given cane price.
